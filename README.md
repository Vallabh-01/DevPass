# DevPass

Your Personal Developer Workspace.

DevPass is a full-stack application that helps developers organize their projects, GitHub activity, learning progress, technical notes, resume information, and development insights in one personal workspace.

## Tech Stack

- React + Vite
- Node.js
- Express.js
- PostgreSQL
- GitHub REST API
- GitHub OAuth
- JWT
- Google Gemini API (optional)
